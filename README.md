# Time Manager

A single-page work-hours tracker. Press **Start** when you begin, **Stop** when you
finish, and the hours land in your phone's browser storage. No account, no server,
no data leaving the device.

**Live:** https://skarphedinnos.github.io/time-manager/

Open that on your phone, then **Add to Home Screen** — installing it is what keeps
the browser from clearing your data, and it launches without browser chrome.

## How it behaves

- **Timer** — the running readout shows the whole unbroken stint, and deliberately
  does not reset at midnight. Pause and resume within a session; paused time never
  counts toward worked hours.
- **Multiple sessions a day** are fine. A session crossing midnight is reported as
  two pieces, one per day.
- **Auto-stop** — a running timer ends at the cutoff (default 22:00). The page can't
  run while closed, so that's applied retroactively when you next open the app, with
  a warning offering an immediate edit. If the app is open when the cutoff arrives,
  it asks "still working?" instead of truncating. A session left *paused* ends where
  the break began, counting only the work before it. Backstop: no session exceeds the
  maximum length (default 16h), which is what catches sessions started late at night.
- **Week and month views** draw each day on a real 24-hour axis — green worked,
  amber paused, plain rest — so a 05:00 start or a late evening is visible at a glance.
  Tap any day to add, edit or delete entries.
- **Backup** — Export hands a JSON file to the share sheet, so it's two taps into
  Drive or Files. Import *merges* by entry id, so importing the wrong file can never
  wipe what's already there.

Hours and sessions read as `7h 30m`; week and month totals as `37.5h`. The week runs
Monday to Sunday. All times follow the device's own timezone.
